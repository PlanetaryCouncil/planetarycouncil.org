# Billionaire Non-Proliferation Treaty — full version

Served at https://planetarycouncil.org/billionaire-treaty/ and linked from `../treaty.html`
(the one-page version) and the homepage treaty section.

- `index.html` — the full treaty: articles, the $17T surplus above the cap (Forbes real-time
  snapshot, 13 Aug 2026: 3,385 people, $20.4T), the costed programme, and **the first ten**
  (`FIRST_TEN` array; `SURPLUS` constant). Nobody listed has been asked or has signed.
- `people/` — one page per person, generated: edit `people/data/<id>.json`, then
  `node build-people.mjs`. A file without `sources` will not build.
